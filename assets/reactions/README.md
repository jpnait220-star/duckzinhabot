# Imagens de reação da Duckzinha

Coloque **suas artes originais** nesta pasta. Use um arquivo por reação com estes nomes:

- `riso.png` — mensagem engraçada ou risadas (KKKK).
- `gg.png` — vitórias, GG e conquistas.
- `surpresa.png` — situações surpreendentes (Eita!).
- `fofo.png` — coisas fofas ou bonitinhas.
- `ola.webp` — saudações (oi, olá, bom dia) **e a imagem mostrada nas boas-vindas**.

Também são aceitos `.webp` e `.gif` (GIF animado). A Duckzinha procura os formatos nessa ordem.

Recomendações: imagens quadradas de 128 a 512 px com transparência (PNG/WebP) e **menos de 2 MB**. Não envie personagens ou artes sem ter permissão de uso.

As imagens são **opcionais**. Se uma categoria não tiver arquivo, ela não envia reação nessa categoria. Não é preciso configurar uma ENV.

Para prevenir spam, as reações de riso/fofura são ocasionais. As saudações têm prioridade quando o intervalo permite. Funciona apenas em canais públicos, com limite global e por canal. Ela não responde a tickets com imagens.
